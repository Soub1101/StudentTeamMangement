# 👨‍💻 Student Team Members Management Application

A full-stack MERN (MongoDB, Express, React, Node.js) web application to manage student team members — including adding, viewing, and inspecting member details with profile image uploads.

---

## 🚀 Project Overview

This application allows users to:

- Add team members with their name, role, email, and profile photo
- View all registered members in a clean layout
- Click on a member to view detailed info

---

## 🔧 Tech Stack

| Layer     | Technology               |
|-----------|--------------------------|
| Frontend  | React.js (with React Router, Axios) |
| Backend   | Node.js, Express.js      |
| Database  | MongoDB Atlas            |
| Image Storage | Server-side `uploads/` folder |

---
## 🛠️ Features

- ✅ Team introduction on homepage
- ✅ Add member form with image upload
- ✅ View list of members with photo, name & role
- ✅ Clickable “View Details” for full member profile
